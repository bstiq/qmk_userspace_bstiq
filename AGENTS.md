# AGENTS

**Before starting any work in this repository, read every file in `agents/`.**

`agents/` is the agent-facing source of truth for this project:

- `agents/next-agent-prompt.md` — the current handoff (what to do next, state, and
  which plan to read).
- `agents/working-notes.md` — standing build/test commands, constraints, and gotchas.
- `agents/README.md` — what the folder is and how it is used.

Do not begin editing code until you have read `agents/` and the plan it points to.
After each task, log the result in the plan's "Task log", update its "WHERE WE ARE"
block, and stop for the user's hardware verification.
